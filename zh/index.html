📊

节省 Token 且准确率高

在 4 个大语言模型的混合结构基准测试中，TOON 的准确率达到 76.4%（JSON 为 75.0%），同时所用 token 减少约 40%。

🔁

JSON 数据模型

使用与 JSON 相同的对象、数组和基本类型进行编码，支持确定性的无损往返转换。

🛤️

LLM 友好的护栏机制

显式的 [N] 长度标记和 {fields} 字段头为模型提供了清晰的模式(schema)指引，提高了解析可靠性。

📐

极简语法

用缩进代替大括号，并尽量减少引号的使用，兼具 YAML 般的可读性和 CSV 般的紧凑性。

🧺

表格化数组

结构一致的对象数组会被折叠为表格，字段只声明一次，行数据逐行流式呈现。

🌐

多语言生态

提供基于规范的 TypeScript、Python、Go、Rust、.NET 等多种语言实现。
